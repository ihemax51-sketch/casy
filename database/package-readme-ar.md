# تحديث قاعدة بيانات KMTGuard

## الطريقة السهلة الموصى بها للعملاء

1. خذ نسخة احتياطية من قاعدة بيانات `KMTGuard`.
2. افتح مجلد أحدث إصدار، مثل `database\v3.0.0`.
3. شغّل الملف الذي يبدأ اسمه بـ `KMTGuard_FULL_DATABASE_UPDATE` مرة واحدة فقط.
4. بعد ظهور رسالة نجاح التحديث، أعد تشغيل الفلتر.

الملف الكامل في إصدار `v3.0.0` يحدّث أي قاعدة عملاء مستقرة من `v2.7.20` أو أحدث إلى `v3.0.0`، ويحتوي جميع التحديثات المطلوبة بعد هذا الإصدار مرتبة تلقائيًا. لا تشغّل الملف الكامل والملفات الفردية معًا.

## الملفات الفردية

الملفات الفردية داخل مجلدات الإصدارات مخصصة للتحديث الانتقائي أو للدعم الفني فقط. مجلد `validation` اختياري ويحتوي فحوصات ما بعد التثبيت، وليس تحديثات أساسية.
